# API 隔离通道

稳定下载入口：[下载最新版](https://github.com/knight9629/api-isolation-channel-releases/releases/latest)

- Apple Silicon Mac：macOS 12 及以上。
- Windows：正式支持 Windows 11 x64；Windows 10 与 Windows ARM 可能不支持。

## 安装

### Mac

1. 打开 DMG，将“API 隔离通道”拖入“应用程序”。
2. 首次打开如被 macOS 拦截，进入“系统设置 → 隐私与安全性”，点击“仍要打开”。

### Windows

1. 下载名称包含 `Windows-x64` 的 EXE 并运行。
2. 安装包未使用 Authenticode，Windows 可能显示“未知发布者”或 SmartScreen 提示。

后续可在软件“设置 → 软件更新”中检查新版本。更新只会在用户确认后下载和安装。

本仓库只用于发布安装包和更新文件，不包含源代码。
